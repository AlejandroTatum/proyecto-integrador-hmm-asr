# Referencias bibliográficas

Esta carpeta separa la bibliografía por etapa del proyecto HMM-ASR.

- `referencias_hmm_asr_curadas.bib`: referencias citadas en el documento del proyecto integrador.
- `fuentes_hmm_asr_28.bib`: corpus activo de 28 fuentes seleccionadas para el tema HMM-ASR.
- `capitulo_21_referencias_ieee.bib`: bibliografía IEEE final usada en el Capítulo 21 de libro.

La versión final del capítulo cita 25 fuentes y todas están enlazadas con DOI cuando corresponde. La validación completa se conserva en `../data/capitulo_21_validacion_final.json`.
