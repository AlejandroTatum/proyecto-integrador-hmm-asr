# Portafolio digital de la Unidad 1

Esta carpeta organiza el cierre del portafolio digital de la Unidad 1 de la asignatura **Metodología de la Investigación en Computación**.

## Entregable para EVA-Moodle

- `portafolio_unidad1_autoevaluacion.pdf`: reporte técnico de cierre de Unidad 1 y autoevaluación reflexiva.
- `reporte_portafolio_unidad_1.tex`: fuente LaTeX del reporte.

El PDF sigue el formato de reporte técnico usado en la materia: encabezado institucional, tabla de datos, secciones numeradas, resultados, autoevaluación, criterios de evaluación y anexos.

## Organización

```text
docs/portafolio_unidad_1/
├── productos/                         # productos PDF de Unidad 1
├── evidencias/                        # checksums y evidencia GitHub
├── AUTOEVALUACION_REFLEXIVA.md        # texto base de autoevaluación
├── reporte_portafolio_unidad_1.tex    # fuente editable del reporte final
└── portafolio_unidad1_autoevaluacion.pdf
```
